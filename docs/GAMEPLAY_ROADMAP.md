# MATCHPOINT 게임플레이 로드맵

## 제품 방향

MATCHPOINT가 남겨야 할 첫인상은 단순한 체육 매칭 앱이 아니라 **포켓몬 GO처럼 지도를
탐험하며 실제 운동 기록으로 지역을 수집하고 이야기를 만드는 앱**이다.

게임성은 경기 결과를 유리하게 만드는 능력치가 아니라 다음 세 가지에서 나온다.

- 지도에서 새로운 체육관을 발견하고 수집하는 즐거움
- 라이벌, 친구, 지역 이용자와 관계가 쌓이는 즐거움
- 시즌마다 목표를 달성하고 칭호·외형을 자랑하는 즐거움

아래의 게임 요소는 정확히 5개다. 모든 보상은 칭호, 배지, 프로필 테두리, 지도 캐릭터·거점
외형 같은 표현 수단으로 제한한다. 스탯 버프, 매칭 우선권 판매, ELO 가산, 유료 전용 승리
효과는 만들지 않는다.

## 공통 공정성 원칙

- ELO는 검증된 경기 결과만으로 변한다. 퀘스트, 방문, 결제, 친구 수는 ELO에 영향을 주지 않는다.
- 게임 보상은 매칭 후보, 팀 편성, 승패 계산에 입력되지 않는다.
- 지도 이벤트 때문에 실력 차가 큰 상대와 강제로 붙이지 않는다.
- 위치만 찍고 떠나는 행동은 인정하지 않는다. 필요한 경우 위치 확인과 완료 경기 기록을 함께
  요구한다.
- GPS는 절대적인 증거가 아니라 보조 신호로 사용한다. 짧은 시간의 비현실적 이동, 반복 위치,
  동일 상대 반복 경기 등은 서버에서 별도로 감지한다.
- 정확한 실시간 좌표와 이동 경로를 다른 사용자에게 공개하지 않는다. 체육관 방문 여부만
  저장하고 지도 공개 정보는 체육관 단위로 집계한다.
- 경기 완료 이벤트는 한 번만 처리한다. 재시도나 중복 웹훅이 보상을 두 번 지급하지 못하도록
  멱등 키를 사용한다.

## 1. 체육관 정복과 지역 도감

### 사용자에게 주는 느낌

지도 위의 체육관은 단순한 핀이 아니라 직접 찾아가 운동해서 밝히는 거점이다. 처음 방문한
체육관은 도감에 실루엣으로 보이고, 그곳에서 유효한 경기를 마치면 건물 일러스트, 방문 스탬프,
지역 설명이 해금된다. 여러 번 활동하면 해당 체육관의 영향력을 쌓아 일시적으로 왕관을 올릴 수
있다.

### 사용자 루프

1. 지도에서 아직 해금하지 않은 가까운 체육관을 발견한다.
2. 해당 체육관을 선택해 정상 매칭을 잡고 실제 경기를 완료한다.
3. 첫 완료 경기로 지역 도감과 방문 스탬프가 열린다.
4. 다른 체육관을 찾아 도감을 채우거나 같은 체육관에서 시즌 영향력을 쌓는다.
5. 구 단위 도감을 완성하면 `강남 셔틀콕 탐험대` 같은 칭호와 거점 외형을 받는다.

### 규칙과 악용 방지

- 첫 수집은 `체육관 반경 내 체크인 + 해당 장소의 완료 경기`가 모두 있어야 인정한다.
- 체육관 영향력은 유효한 완료 경기 1회에 기본 1점으로 단순화한다. 승자는 표시용 보너스 1점을
  받을 수 있지만 ELO와는 무관하다.
- 같은 체육관의 영향력 인정은 하루 1경기, 같은 상대 조합은 주 2경기까지만 허용한다.
- 영향력은 최근 28일 또는 시즌 단위로 초기화해 기존 사용자가 영구 독점하지 못하게 한다.
- 빠른 속도로 먼 체육관을 연속 체크인하면 즉시 보상을 주지 않고 검토 대상으로 둔다.
- 위치 권한이 없을 때는 경기 참가자 합의와 운영자 예약 장소가 일치하는 경우에만 제한적으로
  인정한다. 위치 권한 거부를 부정행위로 단정하지 않는다.

### ELO·매칭과의 분리

도감 완성도와 영향력 점수는 ELO에 포함하지 않는다. 특정 체육관을 정복하려고 눌러도 기존 거리,
종목, 실력 범위의 정상 매칭만 찾는다. 조건에 맞는 상대가 없으면 정복용 봇이나 약한 상대를
제공하지 않는다.

### 화면 노출

- 지도: 미방문 체육관은 반투명 실루엣, 수집 완료는 색이 켜진 3D 체육관, 현재 선두는 작은 왕관
- 체육관 상세: 방문 횟수, 도감 스탬프, 시즌 영향력, 다음 보상
- 프로필: `강남구 3/8`, `서울 3/120`처럼 지역별 수집률
- 경기 결과: `새로운 거점 발견! 잠실 국민체육센터가 도감에 등록되었습니다`

### 필요한 백엔드

- `venue_checkins`: 사용자, 체육관, 시각, 좌표 정확도, 판정 상태
- `venue_collection_entries`: 최초 해금 시각, 완료 경기 ID, 지역 코드
- `venue_season_influence`: 시즌·체육관·사용자별 점수와 인정 경기 수
- `venue_throne_snapshots`: 체육관별 시즌 선두와 스냅숏 시각
- 경기 완료 이벤트를 받아 도감·영향력을 한 번만 반영하는 서버 함수
- 일일·상대 조합 제한, 비현실적 이동 탐지, 시즌 초기화 작업

### 대회 데모 난이도와 우선순위

- 난이도: 중간
- 우선순위: **1순위**
- 대회판: 강남 데모 체육관 3곳만 제공하고, 한 곳은 미발견 상태에서 완료 경기 후 색이 켜지고
  도감이 `2/3 → 3/3`으로 변하는 장면을 실제 데이터로 구현한다.

## 2. 라이벌과 리매치

### 사용자에게 주는 느낌

비슷한 실력의 상대와 여러 번 만나면 단순한 경기 기록이 `라이벌 서사`로 변한다. 서로 한 번씩
이겼거나 점수 차가 작았던 상대에게 라이벌 카드가 생기고, 다음 시즌에 다시 만났을 때 전적과
전용 연출이 나타난다.

### 사용자 루프

1. 정상 매칭에서 비슷한 실력의 상대와 접전을 치른다.
2. 두 번째 유효 경기 또는 1승 1패가 되면 라이벌 관계가 열린다.
3. 결과 화면에서 상대에게 리매치 제안을 보낸다.
4. 두 사람이 가능한 시간대를 고르면 일반 매칭 조건으로 다시 검증한다.
5. 시즌 라이벌 전적을 쌓아 프로필 배너, 결과 연출, 칭호를 해금한다.

### 규칙과 악용 방지

- 라이벌은 사용자가 임의로 아무나 지정하지 못하고, 서버가 유효 경기 기록으로 생성한다.
- 리매치 초대는 수신자가 끌 수 있고, 거절 후 반복 알림을 보내지 못하게 쿨다운을 둔다.
- 동일 상대와의 보상 진척은 주 2경기까지만 인정한다.
- 고의 승패 교환을 막기 위해 짧은 경기 반복, 동일 점수 반복, 같은 기기·위치 패턴을 감지한다.
- 차단·신고 관계인 사용자는 라이벌 후보와 리매치 추천에서 즉시 제외한다.
- 라이벌 공개 범위는 닉네임과 경기 전적뿐이며 연락처나 실시간 위치를 노출하지 않는다.

### ELO·매칭과의 분리

리매치가 랭크 경기라면 현재 ELO 차이와 거리 조건을 다시 통과해야 하며 기존 ELO 계산식을 그대로
쓴다. 조건을 벗어나지만 두 사람이 꼭 경기하고 싶다면 `친선 경기`로 진행하고 ELO는 변하지 않는다.
라이벌 보상은 경기 횟수와 스포츠맨십 중심의 외형 보상이며 승리 가산 능력치를 주지 않는다.

### 화면 노출

- 결과 화면: `새로운 라이벌`, 상대 전적, `리매치 제안` 버튼
- 프로필: 시즌 라이벌 카드와 최근 5경기 결과
- 매칭방: `현재 전적 1:1`과 짧은 라이벌 입장 연출
- 알림: 상대가 제안한 날짜만 전달하고 압박성 연속 알림은 금지

### 필요한 백엔드

- `rivalries`: 두 사용자 정규화 ID, 시즌, 전적, 마지막 경기, 상태
- `rivalry_encounters`: 라이벌 관계에 반영된 경기와 멱등 키
- `rematch_invites`: 제안자, 수신자, 후보 시간, 만료, 수락·거절 상태
- 차단·신고 확인과 초대 속도 제한
- 랭크 리매치 조건 재검사와 친선 경기 분기

### 대회 데모 난이도와 우선순위

- 난이도: 중간~높음
- 우선순위: 4순위
- 대회판: 결과 화면의 라이벌 카드와 리매치 제안·수락 화면은 시연용 상태로 보여 준다. 실제 반복
  상대 감지와 새 매칭 생성은 일주일 범위에서 제외한다.

## 3. 주간 체육관 보스와 왕좌

### 사용자에게 주는 느낌

매주 지도에서 한 체육관이 빛나며 지역 보스가 등장한다. 이용자들이 그 체육관에서 정상 경기를
완료할 때마다 보스 체력이 줄어드는 공동 목표다. 보스를 쓰러뜨리면 참여자 모두가 한정 배지를
받고, 해당 체육관의 시즌 기여 1위는 다음 주까지 지도 타워에 왕관과 닉네임이 표시된다.

### 사용자 루프

1. 지도에서 이번 주 보스 체육관과 남은 체력을 확인한다.
2. 해당 체육관에서 정상 매칭을 잡아 경기를 완료한다.
3. 승패와 관계없이 고정 피해를 주고 개인 기여도를 얻는다.
4. 지역 사용자들과 공동으로 체력을 0까지 낮춘다.
5. 참여 배지와 보스 외형을 받고, 기여 상위 사용자는 일주일간 왕좌에 이름을 남긴다.

### 규칙과 악용 방지

- 보스 피해는 승패나 ELO 차이가 아닌 유효 완료 경기 1회당 고정값이다.
- 사용자당 하루 1회, 동일 상대 조합은 이벤트 기간 2회까지만 피해를 인정한다.
- 보스 체력은 지역 활성 사용자 수를 기준으로 설정하고 진행 중 임의로 올리지 않는다.
- 왕좌는 영구 소유가 아니라 주간 스냅숏이며, 동점이면 먼저 달성한 사용자가 우선한다.
- 매치 취소, 만장일치가 되지 않은 결과, 제재된 경기의 기여는 취소한다.
- 참여 인원이 적어도 달성 가능하도록 주말에는 남은 체력을 보정할 수 있으나 규칙을 미리 공개한다.

### ELO·매칭과의 분리

보스에게 주는 피해와 왕좌 기여도는 ELO와 완전히 별개다. 보스 체육관을 선택해도 정상 실력 범위의
상대만 찾으며, 보스 참여자가 경기에서 유리해지는 버프는 없다. 보스 보상은 배지, 타워 색상,
프로필 오라와 같은 외형뿐이다.

### 화면 노출

- 지도: 빛기둥, 보스 아이콘, 남은 체력, 이벤트 종료 시간
- 체육관 상세: 전체 진행률, 내 기여, 오늘 인정 가능한 남은 경기
- 경기 결과: 보스 피해 연출과 공동 목표 진척
- 지도 타워: 주간 왕좌 사용자 닉네임과 캐릭터 홀로그램

### 필요한 백엔드

- `venue_boss_events`: 체육관, 시작·종료, 체력, 상태, 보상 정의
- `venue_boss_contributions`: 사용자, 경기, 피해량, 인정일
- `venue_thrones`: 이벤트·체육관별 선두, 기여도, 표시 종료 시각
- 경기 완료 이벤트 기반의 원자적 체력 감소 함수
- 주간 이벤트 생성·종료 작업과 보상 일괄 지급
- 무효 경기 발생 시 기여를 되돌리는 보정 이벤트

### 대회 데모 난이도와 우선순위

- 난이도: 중간
- 우선순위: **3순위**
- 대회판: 보스 체육관 하나와 이미 쌓인 공동 진행률을 시드한다. 실제 완료 경기 1회로 체력이
  줄어드는 것까지 연결하되 자동 주간 편성, 대규모 집계, 보상 일괄 지급은 모형 처리한다.

## 4. 친구와 팀 케미

### 사용자에게 주는 느낌

친구와 함께 신청하면 두 사람은 반드시 같은 팀으로 유지되고, 함께 운동할수록 `팀 케미`가
쌓인다. 케미 단계가 오르면 커플·듀오 카드, 합동 입장 연출, 팀 이름과 칭호가 해금된다.

### 사용자 루프

1. 친구를 파티에 초대하고 같은 종목의 매칭을 신청한다.
2. 서버가 두 사람을 고정된 한 묶음으로 유지하면서 공정한 상대 팀을 찾는다.
3. 함께 유효 경기를 완료해 케미 경험치를 얻는다.
4. 새로운 듀오 배너, 입장 포즈, 팀 칭호를 해금한다.
5. 자주 함께한 친구와 한 번에 다시 파티를 만들고 다음 체육관에 도전한다.

### 규칙과 악용 방지

- 파티 신청자는 ELO 차이와 관계없이 같은 팀으로 묶되 매칭 전에 실력 편차 경고를 보여 준다.
- 상대 팀 탐색은 파티 평균뿐 아니라 최고·최저 ELO 편차도 고려한다.
- 공정한 상대를 찾지 못하면 검색 범위를 무한히 넓히지 않고 친선 경기 전환을 제안한다.
- 케미 경험치는 동일 듀오 기준 하루 1경기, 주간 상한을 둔다.
- 경기 취소, 노쇼, 신고 인정 경기는 케미를 올리지 않는다.
- 친구 수나 케미 레벨이 높아도 매칭 우선권, 점수 보정, 능력치를 제공하지 않는다.

### ELO·매칭과의 분리

친구는 항상 같은 팀이라는 제품 약속을 지킨다. 대신 팀의 예상 실력은 종목별 개인 ELO로 계산하고,
상대 팀과 허용 차이 안에서만 랭크 경기를 만든다. 큰 실력 차의 친구 파티는 함께 플레이할 수
있지만 공정한 상대가 없으면 친선 경기로 전환한다. 케미는 외형 해금 수치일 뿐 팀 전투력에
더하지 않는다.

### 화면 노출

- 매칭 설정: `친구와 함께`, 초대 상태, 파티 내 ELO 편차 안내
- 매칭 결과: 고정 파티 표시와 양 팀 예상 실력 차
- 프로필: 자주 함께한 듀오, 케미 단계, 합동 칭호
- 경기 입장·결과: 케미 단계에 따른 합동 연출

### 필요한 백엔드

- `parties`, `party_members`, `party_invites`: 파티 수명주기와 초대 만료
- `duo_chemistry`: 사용자 쌍, 종목, 경험치, 레벨, 마지막 인정 경기
- 팀 단위 매칭 요청과 파티 고정 제약
- 팀 평균·분산을 함께 검사하는 공정성 함수
- 차단·신고 관계 확인과 초대 속도 제한

### 대회 데모 난이도와 우선순위

- 난이도: 높음
- 우선순위: 5순위
- 대회판: 친구 파티, 같은 팀 고정, 케미 결과 카드의 화면 흐름만 모형 데이터로 시연한다. 실시간
  초대, 파티 단위 큐, 공정 팀 편성은 일주일 범위에서 구현하지 않는다.

## 5. 시즌 퀘스트와 코스메틱

### 사용자에게 주는 느낌

매 시즌 지도 탐험과 실제 운동을 묶은 짧은 임무가 열린다. `강남 체육관 3곳 발견`, `서로 다른
상대와 3경기`, `주간 보스 체육관에서 1경기`처럼 MATCHPOINT의 핵심 행동을 자연스럽게 안내하고,
완료하면 공룡 색상, 프로필 테두리, 지도 발자국, 칭호를 얻는다.

### 사용자 루프

1. 지도와 프로필에서 이번 시즌의 3개 핵심 퀘스트를 확인한다.
2. 평소처럼 체육관을 탐험하고 정상 경기를 완료한다.
3. 결과 화면에서 진척이 오르는 즉각적인 피드백을 받는다.
4. 완료 보상을 직접 수령하고 코스메틱 장착 화면으로 이동한다.
5. 장착한 외형을 지도 캐릭터, 결과 카드, 프로필에서 자랑한다.

### 규칙과 악용 방지

- 퀘스트는 완료 경기, 서로 다른 체육관, 서로 다른 상대처럼 서버가 검증할 수 있는 사건만 사용한다.
- 단순 채팅 횟수나 화면 터치처럼 의미 없는 반복 행동을 목표로 만들지 않는다.
- 동일 상대·체육관 반복 인정에는 일일·주간 상한을 둔다.
- 지역에 체육관이 적거나 이동이 어려운 사용자를 위해 `서로 다른 체육관 방문`과 `서로 다른
  상대 경기` 중 하나를 선택하는 대체 목표를 제공한다.
- 보상 수령은 서버 트랜잭션으로 한 번만 처리한다.
- 시즌 종료 직전 진행 중 경기는 경기 시작 시점의 시즌 규칙을 적용한다.

### ELO·매칭과의 분리

퀘스트는 승리보다 참여, 탐험, 스포츠맨십을 중심으로 설계한다. 승리 퀘스트를 넣더라도 ELO 보정은
없고 낮은 상대를 골라 잡을 수 없게 정상 큐에서만 인정한다. 코스메틱에는 명중률, 체력, ELO 보호,
매칭 속도 같은 기능 효과가 없다.

### 화면 노출

- 지도 상단: 시즌 이름, 가장 가까운 완료 목표, 짧은 진행 바
- 체육관 상세: 해당 장소에서 진행 가능한 퀘스트
- 경기 결과: `2/3 체육관 발견`처럼 한 가지 핵심 진척만 강조
- 프로필: 보상 수령, 보유 코스메틱, 장착 미리보기
- 지도: 장착한 공룡 색상, 발자국, 거점 스킨을 다른 사용자에게 과하지 않게 표시

### 필요한 백엔드

- `seasons`: 시즌 기간과 상태
- `quest_definitions`: 조건 유형, 목표값, 대상 지역·종목, 보상
- `user_quest_progress`: 진행값, 완료·수령 시각, 마지막 이벤트
- `cosmetic_items`, `user_cosmetics`, `cosmetic_loadouts`: 보유와 장착 상태
- 경기·체육관 수집 이벤트를 퀘스트 조건으로 변환하는 멱등 이벤트 처리기
- 시즌 시작·종료와 미수령 보상 정책

### 대회 데모 난이도와 우선순위

- 난이도: 낮음~중간
- 우선순위: **2순위**
- 대회판: 퀘스트 3개와 칭호·공룡 테두리 보상 1개만 실제 데이터로 구현한다. 완료 경기 후
  `2/3 → 3/3`, 보상 수령, 장착, 지도 또는 프로필 반영까지 한 흐름으로 보여 준다.

## 1주 경진대회 구현 결론

### 실제로 구현할 것

1. **체육관 정복·지역 도감의 세로 조각**
   - 강남 데모 체육관 3곳
   - 완료 경기 1회로 미발견 체육관 해금
   - 지도 타워 색상 변화, `2/3 → 3/3`, 해금 알림
   - 첫 수집 중복 지급 방지
2. **시즌 퀘스트·코스메틱의 세로 조각**
   - 고정 시즌 하나와 퀘스트 3개
   - 기존 완료 경기·체육관 해금 이벤트로 진척 반영
   - 칭호 또는 프로필 테두리 하나 수령·장착
   - 보상 중복 수령 방지
3. **주간 보스의 데이터 기반 프로토타입**
   - 보스 체육관 하나, 시드된 전체 진행률과 참여자
   - 실제 완료 경기 한 건으로 고정 피해 반영
   - 자동 주간 교체와 대규모 보상 지급은 수동 시드

### 모형으로 처리할 것

- 라이벌 카드와 리매치 제안·수락 화면
- 친구 파티와 케미 결과 카드
- 전국 도감, 자동 시즌 편성, 실제 주간 왕좌 정산
- GPS 부정행위 자동 제재와 대규모 이상 탐지

모형 화면에는 `기능 콘셉트` 또는 `다음 단계`라고 표시해 실제 완성 기능처럼 주장하지 않는다.

### 일주일 작업 순서

| 일차 | 목표 |
| --- | --- |
| 1일차 | 공통 게임 이벤트와 데이터 모델 확정, 데모 체육관·시즌·보상 시드 |
| 2일차 | 경기 완료 → 체육관 도감 해금 백엔드와 중복 방지 |

| 6일차 | 실제 모바일 화면 잘림, 두 계정 전체 흐름, 악용·재시도 검증 |
| 7일차 | 60~90초 시연 리허설, 데모 데이터 초기화, 녹화 예비본 제작 |

## 심사위원에게 보여 줄 한 문장

> MATCHPOINT에서는 지도의 체육관이 단순한 장소 핀이 아닙니다. 실제 경기를 끝내야 지역 도감이
> 열리고, 그 활동이 시즌 퀘스트와 주간 보스에 이어져 운동 자체가 지도 위 게임 진행도가 됩니다.
