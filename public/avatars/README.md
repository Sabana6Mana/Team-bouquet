# 아바타 그림 넣는 곳

이 폴더에 파일을 떨어뜨리면 **코드를 고치지 않아도** 바로 반영된다.
파일이 없는 캐릭터는 이모지로 남으므로, 그린 것부터 하나씩 넣으면 된다.

## 파일 이름

캐릭터 하나당 두 장이 필요하다.

```
<key>.webp        전신  — 매칭 무대, 시상식
<key>-face.webp   얼굴  — 채팅, 목록, 전적 창
```

예: `fox.webp`, `fox-face.webp`

## 쓰이고 있는 key

| key | 이모지 | key | 이모지 |
|---|---|---|---|
| `dino` | 🦖 (나) | `koala` | 🐨 |
| `fox` | 🦊 | `eagle` | 🦅 |
| `bear` | 🐻 | `wolf` | 🐺 |
| `tiger` | 🐯 | `owl` | 🦉 |
| `lion` | 🦁 | `frog` | 🐸 |
| `panda` | 🐼 | `shark` | 🦈 |
| | | `dragon` | 🐲 |

key 는 `src/data/seed.ts` 의 `AVATAR_KEYS` 에서 정한다.

## 그림 규격

| 항목 | 값 |
|---|---|
| 캔버스 | **정사각형**. 전신 512×512, 얼굴 256×256 권장 |
| 형식 | WebP (무손실). PNG 로 만들었으면 변환해서 넣는다 |
| 배경 | **투명**. 흰 배경이면 연승 불길이 가려진다 |
| 방향 | **오른쪽을 보게** 통일. 왼쪽 팀은 코드가 뒤집는다 |
| 바닥선 | 발이 캔버스 **맨 아래에 닿게**. 화면에서 아래를 기준으로 맞춘다 |
| 그림자 | **넣지 않는다**. 발판·그림자·불길은 CSS 가 그린다 |

## 왜 이런 규격인가

- **정사각형** — 화면에서 정사각 칸에 `object-fit: contain` 으로 넣는다. 비율이 다르면 캐릭터마다 크기가 들쭉날쭉해진다.
- **오른쪽 보기** — 매칭 무대에서 두 팀이 마주 본다. 왼쪽 팀에만 좌우 반전을 걸므로 원본은 한 방향으로 통일돼야 한다.
- **바닥선** — 캐릭터가 발판 위에 서 있는 연출이라, 여백이 아래에 남으면 공중에 뜬 것처럼 보인다.
- **얼굴 따로** — 채팅 아바타는 32px 다. 전신을 그 크기로 줄이면 무엇인지 알아볼 수 없다.
